# UE5-Set-Variable-by-Name
Simple C++ class that adds ability to set variable by name with a wildcard value input in BP. Made because I needed to change a ton of different parameters in a loop and didn't want to make bloated function in BP.

How to install:
1. Make sure your project works with C++
2. Copy files into ProjectFolder/Source/ProjectName
3. Build project with Visual Studio or your preferred IDE

How it works:
1. Right click in BP editor -> utilities -> Set Variable by Name
2. Plug in pins as you need, or leave them empty if you want target to be self, or name/value be typed in manually
